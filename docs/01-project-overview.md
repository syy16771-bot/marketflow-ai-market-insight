# 01｜项目概览

## 产品定位

MarketFlow AI 是一个跨境电商市场洞察助手，基于可追溯的商品、竞品与评论样例，输出商品定位、竞品差异、用户痛点和优化建议。

它服务于新品规划和商品优化阶段，核心价值不是替用户做最终决策，而是缩短信息整理时间，并让讨论建立在明确证据之上。

## 目标用户

- 跨境电商产品经理：评估商品机会、规划下一版产品。
- 跨境电商运营：优化 Listing 卖点和商品定位。
- AI 产品与产品运营岗位：关注 AI 能力边界、可信度和评测闭环。

## 核心使用场景

1. 新品方向讨论：从商品描述和竞品矩阵判断定位是否同质化。
2. 商品迭代：从评论证据中识别需要优先解决的使用阻力。
3. Listing 优化：将已验证的用户关注点转化为更准确的表达。

## 产品输出

| 模块 | 回答的问题 |
| --- | --- |
| 商品分析 | 商品面向谁、解决什么问题、信息是否完整？ |
| 竞品分析 | 当前价格和功能差异是什么？ |
| 痛点分析 | 用户在哪些场景遇到什么问题？ |
| 优化建议 | 应优先改产品、Listing 还是定位？ |

## MVP 取舍

当前版本选择三个固定 Demo，而不是实时抓取商业数据。原因是作品集首先需要证明：

- 洞察是否有依据；
- 数字是否可复现；
- AI 是否遵守能力边界；
- 错误结果是否会被系统拦截。

实时搜索、平台数据、销量与市场规模预测都不属于当前验证目标。

## 成功标准

- 三个 Demo 都能生成完整结构化报告。
- 价格、评论数量和频次与确定性结果一致。
- 痛点证据可以回溯到原始评论 ID。
- 每条建议关联有效痛点或竞品机会。
- 用户能区分事实、计算、推断和建议。
